# =============================================================================
# DEEPSEEK V4.1 FLASH — HARDWARE REQUIREMENTS (IMPORTANT — PLEASE READ)
# =============================================================================
#
# This template uses 4x H200 SXM (141 GB HBM3e each = 564 GB total).
#
# V4.1 Flash is a ~552B-parameter MoE model. The FP8 checkpoint is ~511 GB on
# disk (476 GiB). The vLLM recipe lists vram_minimum_gb: 614, but that figure
# assumes NO engram offload. With engram CPU offload (required here) the
# GPU-resident portion drops to ~328 GiB, which at TP4 is ~82 GiB per GPU —
# within the 141 GB budget, leaving ~38.5 GiB per GPU for KV cache.
#
#   MINIMUM CLUSTER SIZE: 4x H200 SXM (TP4).  2x H200 DOES NOT WORK.
#
#   WHY 2x FAILS: At TP2 the non-engram weights are ~164 GiB per GPU, which
#   exceeds the 141 GB HBM3e of an H200 SXM. The engine cannot start even
#   with all memory-saving levers pulled.  You need at least 4 GPUs.
#
#   For more KV headroom or higher concurrency, use 8x H200 (TP8). That
#   drops per-GPU weights further and frees more memory for KV cache.
#
# This template is derived from the official vLLM recipe at:
#   https://recipes.vllm.ai/deepseek-ai/DeepSeek-V4.1-Flash
#
# Changes from the V4 Flash template (H200SXMx4.txt):
#   - Model: DeepSeek-V4-Flash-DSpark -> DeepSeek-V4.1-Flash-1017
#   - Container: vllm-openai:v0.28.0v7 -> vllm/vllm-openai:cu134-nightly
#     (vLLM 0.31.0+ is required; the cppalliance images only go up to 0.28.0v7)
#   - Architecture: encoder-decoder with engram n-gram memory
#   - Tokenizer: --tokenizer-mode deepseek_v41 (new for V4.1)
#   - Attention: --attention-config with FLASHINFER_MLA_SPARSE_DSV41
#   - Engram: --engram-config '{"cpu_offload":true}' (183 GiB tables offloaded)
#   - Spec decoding: 7-token DSpark (V4) -> 5-token DSpark (V4.1, no MTP)
#   - Reasoning parser: deepseek_v4 -> deepseek_v41
#   - Tool call parser: deepseek_v4 -> deepseek_v41
#   - Reasoning effort: "max" (too expensive on V4.1) -> "high" (effort 50)
#   - --enable-expert-parallel removed (deprecated for V4.1)
#   - --enable-ep-weight-filter removed (deprecated for V4.1)
# =============================================================================
